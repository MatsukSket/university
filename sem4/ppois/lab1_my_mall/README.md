# Симулятор Торгового Центра

Интерактивное консольное приложение на Python, имитирующее работу торгового центра. 

Проект спроектирован с использованием принципов объектно-ориентированного программирования (ООП), `dataclasses` для моделей и строгим разделением ответственности (Модели, Сервисы, Пользовательский интерфейс).

## Особенности проекта

* **Полноценный CLI-интерфейс:**
  * **Поиск товаров:** удобный поиск продуктов по названию по всем магазинам галереи.
  * **Покупки:** система покупки товаров с автоматическим списанием средств, уменьшением складских остатков и зачислением выручки в кассу магазина.
  * **Промоакции:** возможность включать и выключать участие покупателя в акциях (скидках).
  * **Рейтинговая система:** покупатели могут оценивать качество обслуживания продавцов (от 1.0 до 5.0), рейтинг пересчитывается динамически.
  * **Профиль:** просмотр инвентаря купленных товаров.
* **Надежная бизнес-логика:**
  * Использование кастомных исключений (`OutOfStockError`, `InsufficientFundsError`, `ShopNotFoundError` и др.) для безопасной обработки ошибок.
  * Работа с памятью и копированием объектов при покупке (модуль `copy`).
* **Модульное тестирование:**
  * Встроенный набор тестов с использованием фреймворка `pytest`, покрывающий все основные модели, сервисы и пограничные случаи.

```text
├── main.py                 # ТОЧКА ВХОДА (Инициализация данных и запуск)
└── README.md
```
