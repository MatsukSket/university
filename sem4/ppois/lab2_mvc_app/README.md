# База Данных Студентов  

Десктопное приложение на Python с графическим интерфейсом (GUI) для учета и управления информацией о студентах и составе их семей. 

Проект спроектирован со строгим соблюдением архитектурного паттерна **MVC (Model-View-Controller)**, что обеспечивает четкое разделение логики работы с данными, интерфейса и управления.

## Особенности проекта

* **Полноценный графический интерфейс (PySide6):**
  * **Два режима отображения:** мгновенное переключение между классической таблицей (`QTableView`) и иерархическим деревом (`QTreeView`).
  * **Продвинутая пагинация:** настраиваемое количество строк на странице и удобная навигация (Первая, Предыдущая, Следующая, Последняя страницы).
  * **Диалоговые окна:** пользовательские окна для безопасного ввода данных и поиска.
* **Гибкая работа с данными (SQLite):**
  * Многокритериальный поиск и удаление: возможность искать или удалять студентов по точным совпадениям (имена) или диапазонам значений (зарплаты родителей, количество братьев/сестер).
  * Динамическое формирование SQL-запросов на основе введенных пользователем фильтров.
* **Импорт и Экспорт XML:**
  * Сохранение текущей базы данных в формат XML с использованием `xml.dom.minidom` для красивого форматирования.
  * Загрузка данных из XML-файлов с помощью потокового парсера `xml.sax` для быстрой и эффективной обработки.

## Структура данных (Сущность «Студент»)
Каждая запись в базе хранит следующую информацию:
* Имя студента
* ФИО и заработок отца
* ФИО и заработок матери
* Количество братьев и сестер
